# Bundle Resources

This directory contains resources that are bundled into the macOS/Windows/Linux app packages.

## Contents

- `macos/fhub-cli.jar` - CLI tool (generated by `:cli:shadowJar`)

## How it works

The `copyCliJarToBundle` task in `composeApp/build.gradle.kts` copies the CLI JAR here before packaging.

This directory is referenced by `appResourcesRootDir` in the native distributions config.
