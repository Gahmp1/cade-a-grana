# Cadê a Grana? (FinanceHubKMP) — ARQUIVADO

> **Este projeto foi aposentado e o repositório está arquivado (somente leitura).**
> O produto continua como **Somma**: <https://somma.devaocubo.me> (web, iOS e Android).
> Não há app de desktop no momento.

Foi um sistema de análise financeira em Kotlin Multiplatform + Compose Multiplatform que processava
extratos bancários (Itaú, PicPay) e gerava relatórios mensais e consolidados. Os parsers, a
categorização e os relatórios foram portados para o backend do Somma (Go), e o CLI Kotlin deixou de
ser usado como oráculo de paridade em 2026-07-25.

O código e a release `v1.0.0` ficam aqui apenas como referência histórica.
